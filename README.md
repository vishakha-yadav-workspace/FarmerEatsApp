# Software Lab Assignment – Mobile App

## Overview
This mobile application is developed as part of the Software Lab Mobile App Developer assignment.

The app includes:
- Splash Screen
- Onboarding Screens
- Login Screen
- Register Screen
- REST API Integration

## Features Implemented

### Splash Screen
- Displays app logo
- Auto navigates to onboarding screen

### Onboarding
- 3 onboarding screens
- ViewPager2 with dot indicator
- Navigation to login screen

### Authentication
- Login using REST API
- Register using REST API
- Form validation
- Proper error handling

### API Integration
- Implemented using Retrofit
- Handles success and failure responses
- Displays error messages properly

## Tech Stack Used
- Kotlin
- XML Layouts
- MVVM Architecture
- Retrofit
- ViewBinding
- Navigation Component

## How to Run the Project
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run the app on emulator or physical device
